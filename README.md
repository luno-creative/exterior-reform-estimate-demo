# 外壁塗装・リフォーム 見積もりデモ

## サービス概要

建物の種類や延床面積、塗料のグレード、施工内容などを選択することで、外壁塗装・リフォームの概算費用を自動計算できるWeb見積もりツールです。

施工内容に応じた料金の目安を、お客様自身で簡単に確認できます。

## デモサイト

https://luno-creative.github.io/exterior-reform-estimate-demo/

## 主な機能

- 建物種別の選択
- 延床面積の入力
- 塗料グレードの選択
- 外壁塗装の概算料金計算
- 屋根塗装オプション
- 建物の補修オプション
- 防水施工オプション
- 希望施工時期の選択
- 選択内容に応じた料金の自動計算
- 見積もり内容の確認

## 使用技術

- HTML
- CSS
- JavaScript

## 操作方法

1. デモサイトにアクセス
2. 建物の種類を選択
3. 延床面積を入力
4. 希望する塗料グレードを選択
5. 屋根塗装・補修・防水などのオプションを選択
6. 希望施工時期を選択
7. 自動計算された概算料金を確認

## 制作目的

外壁塗装・リフォーム事業者向けのWeb見積もりシステムのデモとして制作しました。

お客様が施工内容と費用の目安を事前に把握できるようにし、問い合わせのハードルを下げることを目的としています。

## 注意事項

本サイトは営業・提案用のデモサイトです。

表示される料金や施工内容はサンプルであり、実際の施工会社の料金体系を示すものではありません。
